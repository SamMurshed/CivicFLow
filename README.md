# CivicFlow

CivicFlow is a full-stack, fictional public-sector procurement operations portal. It demonstrates secure role-based workflows for agency applicants, procurement analysts, vendors, and administrators using synthetic data only.

The application source, setup guide, architecture, testing instructions, and deployment documentation are in [`ProjBob/`](./ProjBob/README.md).

## Portfolio Highlights

- Structured request submission with category-based document requirements
- Private Supabase Storage uploads and expiring document links
- Analyst queues, checklist review, correction cycles, decisions, notifications, and audit history
- Operational analytics, accessible visual summaries, and formula-safe CSV export
- Searchable guidance and user-feedback workflows
- Strict TypeScript, Row Level Security, Vitest, Playwright, and GitHub Actions

> Demonstration project: every organization, person, budget, request, and document is fictional.
